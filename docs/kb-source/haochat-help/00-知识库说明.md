# HaoChat 帮助知识库说明

## 适用范围

本知识库面向 HaoChat 当前已实现的账号、好友、私聊、群聊、语音消息和 AI 助手功能。资料用于回答产品使用问题，不包含真实用户资料、聊天内容、密码、验证码、令牌或服务器密钥。

## 回答原则

1. 只根据已发布资料回答，不确定时明确说明并建议用户补充页面、报错或操作步骤。
2. 不猜测用户密码、验证码、登录状态或后台数据。
3. 涉及发送消息、发布群公告、创建提醒等会改变数据的操作，应说明影响；AI 助手的高风险操作需要用户确认。
4. 涉及权限时，以群主、管理员、普通成员的实际角色为准。
5. 回答应优先给出操作路径、前置条件、预期结果和失败排查方式。

## 资料边界

本知识库不是用户记忆库。用户对话记忆、私人聊天记录和个性化信息必须按账号隔离，不能作为公共帮助资料写入 `haochat_help` 空间。
