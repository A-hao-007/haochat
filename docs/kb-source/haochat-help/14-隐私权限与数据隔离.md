# 隐私、权限与知识数据隔离

## 敏感信息

密码、邮箱验证码、访问令牌、刷新令牌、服务器密钥和私人聊天原文都不应写入公共知识库。排障截图和日志需要先脱敏。

## 权限校验

联系人、私聊、群聊和 AI 工具调用都必须在服务端校验当前用户身份。前端隐藏按钮只是体验优化，不能代替服务端鉴权。

## 三类数据必须分开

1. 公共产品知识：HaoChat 功能说明、操作指南和常见问题，可进入 `haochat_help`。
2. 用户个性化记忆：偏好和经授权提取的对话记忆，必须按用户隔离。
3. 原始业务数据：好友关系、群成员、消息、任务等，保留在业务数据库，由授权工具按需读取。

公共知识检索不能返回其他用户的记忆或原始聊天数据。删除或更新知识文档时，也要同步清理对应向量，避免旧内容继续被召回。
