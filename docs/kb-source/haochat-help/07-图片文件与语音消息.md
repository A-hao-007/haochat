# 图片、文件与语音消息

## 图片和文件

在消息输入区使用图片或文件入口选择内容并发送。上传前核对文件，避免在错误会话发送隐私资料。上传失败时检查网络、文件是否仍存在、文件类型和大小是否符合页面限制。

## 发送语音

点击麦克风入口并授权浏览器使用麦克风，开始录音后按页面提示结束并发送。第一次使用时浏览器可能请求权限；拒绝后需要在浏览器站点设置中重新允许。

## 语音播放失败

- 检查设备音量和浏览器是否静音。
- 确认语音文件已经完成上传。
- 刷新会话后重试，避免重复发送。
- 若只有某条消息失败，记录消息时间和会话，不要公开转发私人语音用于排障。
