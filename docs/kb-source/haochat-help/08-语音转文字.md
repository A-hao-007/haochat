# 将收到的语音消息转成文字

## 操作方法

1. 在会话中找到对方发送的语音消息。
2. 在该语音消息上打开右键菜单。
3. 选择“转文字”。
4. 等待识别完成，结果显示在对应语音消息附近。

语音转文字是消息右键菜单里的按需操作，不应默认占用输入框工具栏，也不会自动转写所有语音。

## 识别限制

背景噪声、音量太低、多人重叠说话、口音、语音过短或文件损坏都会影响识别。转写仅供辅助理解，重要信息应回放原语音或向发送者确认。

## “未识别到清晰语音”

这表示接口已处理但没有得到可靠文本。先播放确认语音是否清晰，再重试一次；仍失败时保留原语音，不要把错误转写当成发送者原意。
