# 创建、邀请和加入群聊

## 创建群聊

进入“群组”页面选择创建群聊，填写群聊信息并从好友中选择初始成员。创建成功后，创建者成为群主，群聊会出现在“我的群组”和消息会话中。

## 邀请好友

在群组管理中选择“邀请好友入群”。候选列表来自当前好友，已经在群里的账号应被自动排除或标记，避免重复邀请。提交前核对选中成员。

## 无法邀请

- 对方不是当前账号好友。
- 对方已经是群成员。
- 当前成员没有邀请权限。
- 群聊状态或登录状态已经变化。

群聊和联系人页面职责不同；群组功能应从“群组”或当前群会话的管理入口进入。
