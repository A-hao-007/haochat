# 账号切换、历史账号与退出

## 切换账号

在“我的主页”选择“切换账号”，返回登录页后选择历史账号或输入另一个账号。历史账号卡片会回填账号标识；只有存在有效安全凭证时才能快捷登录，否则仍需密码或邮箱验证码。

## 删除历史账号

登录页每个历史账号卡片右上角有删除按钮。删除只会清理当前浏览器保存的账号显示信息和本地凭证，不会注销服务器上的 HaoChat 账号，也不会删除服务器聊天记录。

## 退出登录

“退出登录”会结束当前会话并返回登录页。多人共用设备时，退出后还应删除不需要保留的历史账号，避免暴露头像、昵称或账号标识。

切换账号用于快速进入另一个账号的登录流程；退出登录用于结束当前会话。两者都不能绕过新账号的身份验证。
