# 常见问题与故障排查

## 通用排查顺序

1. 记录时间、当前账号、页面、操作步骤和完整错误提示。
2. 确认网络、登录状态和页面是否加载完成。
3. 刷新一次并复现，避免反复提交写入操作。
4. 判断是单个账号、单条数据、单个浏览器，还是所有用户均受影响。
5. 管理员再检查接口状态码、后端日志、数据库和外部依赖。

## 头像或昵称异常

先区分页面缓存与服务器资料：重新登录或刷新后仍异常，再检查用户接口返回的头像地址和昵称。修复应针对缓存键、数据映射或资源访问规则的通用原因，不能只清理某一个账号的缓存。

## 消息发送后没有结果

确认会话仍有效、消息未重复出现、接口没有报错。AI 消息还要检查运行是否等待确认、已取消、模型失败、检索失败或工具超时。

## 何时需要服务端排查

多个账号在不同浏览器稳定复现、接口持续返回错误、数据与权限状态不一致，或刷新后问题仍存在时，应进入服务端排查。提交信息要脱敏，不能包含密码、验证码或令牌。
