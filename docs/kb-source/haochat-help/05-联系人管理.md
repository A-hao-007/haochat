# 联系人管理

## 查看联系人

联系人页集中展示好友数量、好友列表、收到的申请和发出的申请。联系人与群组是不同对象：联系人页管理一对一好友关系，群组页管理多人会话和群成员。

## 好友备注

可以为好友设置仅自己可见的备注。备注不会修改对方账号昵称，也不会向对方公开。

## 发起私聊

从联系人列表选择好友后进入一对一会话。若好友关系已解除，应以当前接口返回状态为准，不能继续把对方当作有效好友处理。

## 删除好友

删除好友会解除双方好友关系，属于会改变账号数据的操作。执行前应核对目标用户；删除后如需恢复，要重新发送好友申请。删除好友不等于删除对方账号。
