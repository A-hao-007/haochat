# 邮箱验证与找回密码

## 忘记密码

1. 在登录页选择“忘记密码”。
2. 输入账号绑定邮箱并获取验证码。
3. 提交验证码完成身份验证。
4. 设置并确认新密码。
5. 使用新密码重新登录。

找回密码必须先验证邮箱身份，不能只知道用户名就直接重置。验证码是一次性安全凭证，不要转发给任何人。

## 已登录时修改密码

从“我的主页”进入修改密码。系统会先校验当前身份，再允许设置新密码。修改成功后旧密码失效，其他设备上的会话可能需要重新登录。

## 收不到验证码

- 确认邮箱与账号绑定邮箱一致。
- 检查垃圾邮件、广告邮件和邮箱拦截规则。
- 等待倒计时结束后再重新发送，避免连续请求。
- 只使用最后一次发送的验证码。
- 仍失败时记录时间、邮箱脱敏值和页面错误提示，交给管理员排查邮件服务日志。
