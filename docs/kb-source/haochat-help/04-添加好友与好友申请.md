# 添加好友与处理好友申请

## 发起申请

1. 打开“联系人”。
2. 在“添加新好友”搜索框输入用户名或昵称。
3. 从结果中核对头像、昵称和账号标识。
4. 点击添加并发送好友申请。

不能添加自己；已经是好友或已有待处理申请时，页面会显示对应状态，避免重复建立关系。

## 处理申请

联系人页包含“收到申请”和“发出申请”。收到申请可接受或拒绝；接受后双方进入联系人列表并可开始私聊。发出申请用于查看自己已发送申请的处理状态。

## 添加按钮不可用

- 搜索词为空或没有匹配用户时不会出现可添加对象。
- 对方已经是好友、申请正在等待处理或目标是自己时不能重复添加。
- 登录过期时先重新登录。
- 页面有明确错误时，保留提示和操作时间再排查接口。
