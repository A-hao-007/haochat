# 发送与管理聊天消息

## 发送文本

打开私聊或群聊，在底部输入框输入内容。按 Enter 发送，按 Shift+Enter 换行。发送按钮不可用时，先检查输入是否为空、当前会话是否有效以及登录是否过期。

## 消息状态

消息发送后会显示相应状态，系统也会记录会话的已读进度。网络异常时不要连续重复点击，应先确认消息列表中是否已出现该消息。

## 消息菜单

需要管理消息时，在具体消息上打开右键菜单，而不是只把鼠标停在文本框上。菜单会根据消息类型、发送者、时间和权限提供可用操作。

## 编辑、撤回和标记

- 编辑：修改自己符合条件的消息，结果以页面提示为准。
- 撤回：撤回符合条件的消息，会话中保留撤回提示。
- 标记：用于收藏或突出需要后续处理的消息。

若菜单没有某项操作，通常表示当前消息类型、身份或状态不满足条件。
