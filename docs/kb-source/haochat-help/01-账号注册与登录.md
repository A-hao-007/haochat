# 账号注册与登录

## 注册账号

1. 在登录页切换到“注册”。
2. 填写用户名、昵称、密码、确认密码和邮箱。
3. 获取并填写邮箱验证码。
4. 根据页面校验提示，确认两次密码一致后提交。

用户名用于识别账号，昵称用于界面展示。密码要求以注册页的实时提示为准；前后端都应校验，不能只依赖浏览器提示。

## 登录方式

HaoChat 支持账号密码登录和邮箱验证码登录。前者需要用户名或邮箱及正确密码；后者需要向已绑定邮箱获取有效验证码。

浏览器保存过的历史账号只是便于选择账号，并不代表可以绕过身份验证。若该账号仍有有效刷新凭证，可安全快捷登录；凭证失效时仍需密码或邮箱验证码。

## 登录失败排查

- 不要混淆用户名、昵称和 HaoChat ID。
- 检查邮箱、密码前后的空格和大小写。
- 使用最新收到且仍在有效期内的验证码。
- 历史账号点击后仍要求密码，通常说明本地没有有效刷新凭证，这是正常安全行为。
