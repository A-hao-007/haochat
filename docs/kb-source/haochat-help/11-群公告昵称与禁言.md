# 群公告、群昵称、禁言与退出群聊

## 群公告

群主或有权限的管理员可发布群公告，成员可以查看公告并记录已读状态。发布会影响全体群成员，应先确认内容、群聊和通知范围。

## 我的群昵称

成员可设置自己在当前群聊中的群昵称。群昵称只在该群中展示，不会修改账号全局昵称。

## 禁言与解除禁言

有权限的管理者可以禁言或解除禁言成员。普通成员不能自行对他人执行该操作。被禁言后能否发送消息以当前页面状态和服务端校验为准。

## 退出群聊

普通成员可在群组管理的危险区选择退出群聊。退出后需要再次被邀请才能加入。群主若要退出，应先按系统流程处理或转让群主身份。

## 操作日志

群聊的重要管理动作应进入操作日志，便于追踪谁在什么时间执行了何种变更。
